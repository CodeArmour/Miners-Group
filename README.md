# Miners Group Website Brief

This folder contains the source content and product direction for the Miners Group introductory website.

## Agent Instructions

1. Read `WEBSITE_CONTENT.md` completely before implementing pages or components.
2. Treat it as the source of truth for website messaging, page structure, audience, services, programs, and CTAs.
3. Do not invent company statistics, testimonials, partnerships, clients, social URLs, team members, or project results.
4. The first version is primarily an introduction to Miners Group, its mission, goals, services, programs, and opportunities.
5. Build reusable components and content structures so real programs, projects, opportunities, and backend/CMS data can replace static content later.
6. Keep the dual audience clear: students/developers seeking growth and companies/organizations seeking software or collaboration.

## Main Content File

- `WEBSITE_CONTENT.md` — complete website content and implementation guidance.


## Design File

- `DESIGN_DIRECTION.md` — complete UI/UX direction, visual system, homepage composition, interaction rules, responsive behavior, and component guidance.
- Implementation agents should read `WEBSITE_CONTENT.md` first and `DESIGN_DIRECTION.md` second before building or redesigning the UI.
